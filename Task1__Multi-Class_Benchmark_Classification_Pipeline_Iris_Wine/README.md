
# Task 1: Multi-Class Classification Pipeline

## Internship
Datheon_Machine_Learning_&_Data_Science_Internship

## Project Overview
This project implements a multi-class classification pipeline using the Iris dataset.

The objective is to predict the species of an Iris flower based on four measurements:
- Sepal length
- Sepal width
- Petal length
- Petal width

## Dataset
The Iris dataset contains 150 samples belonging to three species:
- Setosa
- Versicolor
- Virginica

## Machine Learning Models
1. Logistic Regression
2. Decision Tree Classifier

## Methodology
1. Data loading and exploration
2. Data visualization
3. Feature and target separation
4. Train/test splitting (80/20)
5. Feature scaling
6. Model training
7. Model evaluation
8. Model comparison

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
